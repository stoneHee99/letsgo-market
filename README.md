# 함께걷장 · 야시장 퍼즐 대작전 🏮

> ⚠️ **부스 QR 전량 인쇄 완료 (2026-08-11).** 인쇄된 QR이 계속 동작해야 하므로 다음은 절대 변경 금지:
> `src/lib/codes.ts`의 SALT·토큰 로직·URL 형식(`?s=`), `src/lib/booths.ts`의 항목 **순서**,
> 배포 주소(레포 이름 `letsgo-market`). 부스 이름/설명 텍스트 수정은 안전.

교회 청년 수련회용 야시장 부스 게임 웹앱.
각 조가 부스에 참여하고 QR을 찍으면 퍼즐 조각을 얻고, 16조각을 모아 수련회 포스터를 완성합니다.

**서버 없는 완전 정적 앱**입니다 — 조별 진행상황은 조장 폰의 브라우저(localStorage)에 저장되고,
QR 생성/인식 모두 브라우저에서 처리됩니다. 아무 정적 호스팅에나 올리면 됩니다.

## 실행

```bash
pnpm install
pnpm dev        # 개발 서버
pnpm build      # dist/ 에 정적 빌드
pnpm preview    # 빌드 결과 미리보기
```

## 운영 흐름

1. **배포** — `pnpm build` 후 `dist/`를 정적 호스팅에 업로드 (Vercel, Netlify, GitHub Pages 등).
   ⚠️ 카메라 스캔은 **https** 에서만 동작합니다 (localhost 제외).
2. **QR 인쇄** — 배포된 주소에서 `https://<주소>/#/admin` 접속 → [전체 인쇄].
   - **참가자 접속 QR**: 수련회 시작 때 각 조장이 찍고 들어와 조를 선택
   - **부스 QR 16장**: 각 부스에 부착. 부스 미션을 완수한 조에게 보여주면 됨
   - QR에는 현재 접속 주소가 담기므로 반드시 **실제 배포 주소에서 열어 인쇄**하세요.
3. **게임** — 참가자 앱에서 QR 스캔(📷 탭) 또는 폰 기본 카메라로 QR을 찍으면
   해당 부스의 퍼즐 조각이 지급됩니다. 16조각 완성 시 축하 화면이 나옵니다.

### 부스 QR이 안 찍힐 때

- 스캔 탭 하단의 **수동 코드 입력** 사용 (인쇄 카드에 `수동코드 01-K3TZ` 형태로 표기됨)
- 코드에는 검증 토큰이 붙어 있어 번호만 추측해서 입력하는 부정행위는 막힙니다.

## 커스터마이징

| 무엇 | 어디 |
| --- | --- |
| 부스 이름/구역 (16개) | `src/lib/booths.ts` |
| 행사명·문구·조 개수 | `src/lib/config.ts` |
| 퍼즐 완성 그림 | `public/poster.jpg` 교체 (다른 비율이면 `styles.css`의 `--poster-aspect`도 수정). `public/puzzle.svg`는 예비용 일러스트 |
| QR 위조 방지 토큰 | `src/lib/codes.ts`의 `SALT` 변경 → 모든 QR 재발급 |

## 테스트 팁

- `https://<주소>/?demo=1` 로 접속하면 스캔 탭에 **스캔 시뮬레이션** 버튼이 생겨
  QR 없이 전체 흐름(조각 획득 → 퍼즐 → 완성)을 확인할 수 있습니다.
- 홈 탭 맨 아래 **팀/기록 초기화**로 처음부터 다시 시작할 수 있습니다.

## 구조

- `src/App.tsx` — 라우팅(참가자 앱 / `#/admin`) + 게임 상태 흐름
- `src/components/` — 홈·부스·스캔(jsQR 카메라 인식)·퍼즐 탭, 조각 획득 모달, 완성 화면, 온보딩
- `src/pages/AdminPage.tsx` — 부스 QR 카드 생성·인쇄 (`qrcode` 라이브러리)
- `src/lib/` — 부스 데이터, QR 코드 토큰 검증, localStorage 상태
